# SourceArt

Working files for assets made during the jam. They live outside `Content/` so Unreal doesn't auto-import them.

- `Blender/`: .blend files → export .fbx into `Content/`
- `Ableton/`: Ableton Live projects (.als) + recorded audio → export .wav stems into `Content/Audio/`
- `Textures/`: source images and generated textures before import

Committing these gives a timestamped record that every asset was made during the jam.
